Git va GitHub bir xil narsami? +

Yo‘q. Git kompyuteringizdagi versiyalarni boshqaradi. GitHub esa Git repositorylarini internetda saqlash va boshqalar bilan hamkorlik qilish xizmatidir.

Ikki akkaunt uchun ikkita kompyuter kerakmi? +

Kerak emas. SSH konfiguratsiyasi va repositoryga xos Git identifikatsiyasi orqali ish va shaxsiy akkauntlarni bitta qurilmada alohida ishlatish mumkin.

Darslarni boshlash uchun nimalar kerak? +

Kompyuteringizda Git o‘rnatilgan bo‘lsa kifoya. GitHub akkaunti keyingi masofaviy repository mavzularida kerak bo‘ladi.
